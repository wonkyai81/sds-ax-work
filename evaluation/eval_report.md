입력: `evaluation/test_queries.csv` (12건, 변경 없음). 기준: 12/12 통과.

## PM 체크리스트 (건별 1회 확인)
- [ ] 같은 지역을 불필요하게 오가지 않는다
- [ ] 식사 시간대(아침/오후/저녁)에 식사 일정이 있다
- [ ] 장소가 실제로 있는 곳으로 보인다

## 현재 상태: 12/12 **미검증**
실제 모델(Bedrock) 실행이 필요한 평가이며, 이 작업 환경에는 `.env`(AWS_DEFAULT_REGION, BEDROCK_MODEL_ID)와 AWS 자격 증명이
없고 `streamlit` 도 설치되어 있지 않아 12건 실행과 수동 시연(Streamlit)을 하지 못했다. 또한 자동 점검 스크립트
`evaluation/run_eval.py` 는 TASKS 문서상 사용자 허가가 필요해 만들지 않았다.

규칙 파서(`src/api.py: parse_trip`) 로 12건 입력을 점검한 결과(모델 불필요):

| ID | 파싱 결과 | 비고 |
|---|---|---|
| TQ-01 | 도쿄 / 4일 / 1,000,000원 | 정상 |
| TQ-02 | 서울 / 3일 / 500,000원 | 정상 |
| TQ-03 | 교토 / 5일 / 1,500,000원 | 정상 |
| TQ-04, TQ-05 | 여행 정보 없음 | 세션 재개 요청이므로 정상 (session_id 필요) |
| TQ-06 | 없음 | 실시간 조회 불가 안내 응답이 아직 없음 (422 반환) |
| TQ-07 | 여행지 '정확한' 로 오인 | 개선 필요 |
| TQ-08 | 여행지 없음 / 4일 / 1,000,000원 | 되묻기 응답이 아직 없음 (422 반환) |
| TQ-09 | 제주 / 6일 / 10,000원 | 정상 (재조정·경고는 그래프가 처리) |
| TQ-10 | 도쿄 / 4일 / 1,000,000원 | 조건 충돌 안내가 아직 없음 |
| TQ-11, TQ-12 | 없음 | 거절 안내 응답이 아직 없음 (422 반환) |

## 남은 일 (사용자 확인 필요)
1. `evaluation/run_eval.py` 생성 허가와 Bedrock 설정(.env) 제공.
2. TQ-06·07·08·10·11·12 의 안내·거절 응답 설계 (DESIGN.md 에 규정 없음).
3. `pip install streamlit` 후 `streamlit run src/ui.py` 로 수동 시연.
